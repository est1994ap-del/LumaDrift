# Changelog

## 1.0.0 — 2026-09-26

- Introduced LumaDrift with a new futuristic name and custom application icon.
- Added a double-click macOS installer for Apple-silicon Macs.
- Added a one-button first-run setup with no Terminal or developer tools required.
- Added a native SwiftUI wallpaper selector with standard Mac window controls.
- Added a continuously looping, silent, click-through desktop renderer.
- Added Apple motion-wallpaper discovery through the local macOS catalog.
- Added display-shaped 5K, 60 fps, 10-bit HEVC preparation with Metal and Core Image.
- Added custom video import with managed copies and generated thumbnails.
- Added multi-display, Spaces, wake, and login support.
- Kept display sleep and battery-saving behavior under macOS control.
