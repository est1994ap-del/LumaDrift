# LumaDrift 1.0.0

Motion, uninterrupted.

LumaDrift turns compatible Apple motion wallpapers—or almost any video on your
Mac—into a continuously moving desktop. This first release includes a native
selector, one-button setup, a click-through background renderer, high-quality
video preparation, and automatic startup at login.

## The easy install

1. Download `LumaDrift-1.0.0-macOS-arm64.pkg` below.
2. Double-click it and finish the Mac installer.
3. Open LumaDrift from Applications.
4. Click **Set Up LumaDrift**.
5. Choose a wallpaper and click **Set Live Wallpaper**.

No Terminal commands or developer tools are needed. Because this independent
first release is not yet Apple-notarized, macOS may ask you to Control-click
the package and choose **Open** once.

## Highlights

- Continuously plays behind Finder icons while you use the Mac.
- Discovers compatible Apple motion wallpapers from the Mac's own catalog.
- Imports your own video with **Add Video…**.
- Prepares Apple video as display-shaped 5K, 60 fps, 10-bit HEVC.
- Restores the selected background automatically at login.
- Supports multiple displays and macOS Spaces.
- Preserves normal macOS display-sleep and battery-saving behavior.

## Before setup

- Requires an Apple-silicon Mac running macOS 14 or later.
- Internet access is needed for Apple wallpaper downloads.
- First-time preparation can take a while and use several gigabytes.
- Apple media is downloaded directly from Apple and is not included in this release.

The source ZIP and `SHA256SUMS.txt` are included for developers and independent
verification. LumaDrift is open source under the MIT license and is not
affiliated with Apple.
